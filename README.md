# AWS-CloudTrail-Threat-Hunter 🛡️☁️

An automated cloud security log analysis and threat hunting engine built in Python. Features AWS CloudTrail schema parsing, heuristic threat detection for root logins and open security groups, and real-time security telemetry dashboards.

## 🚀 5-Day Development Roadmap

- [x] **Day 1:** CloudTrail Log Ingestion & Schema Normalization Parser
- [ ] **Day 2:** Heuristic Security Analyzers (Root login & public security group detection)
- [ ] **Day 3:** Statistical API Volume Anomaly Detection
- [ ] **Day 4:** Automated Incident Response & IAM Policy Generator
- [ ] **Day 5:** Real-Time Terminal Security Feed & SIEM Alert Exporter
